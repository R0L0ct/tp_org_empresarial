

    # Trabajo Práctico: Gestión Colaborativa, Control de Versiones y Organización Empresarial (Git, GitHub y Jira)

Este repositorio contiene la solución técnica para el análisis estadístico y la visualización de datos de ventas. La implementación se ejecutó bajo un flujo de ingeniería reproducible gestionado íntegramente desde el entorno de **Google Colab** e integrado con metodologías de control en **Jira**.

---

## Gobierno del Proyecto y Roles (Scrum)
Para la ejecución de este ciclo, el equipo distribuyó las responsabilidades simulando un entorno profesional:

* **P1 - Líder y Organizador (Hugo):** Responsable de establecer la gobernanza inicial del repositorio central en GitHub, definir el árbol estructurado de directorios de ingeniería y redactar la documentación de visión general del proyecto.
* **P2 - Desarrollador Técnico (Paco):** Responsable del diseño e implementación de la lógica algorítmica en Python, garantizando un script reproducible mediante el uso estricto de rutas relativas y la correcta exportación de subproductos técnicos.
* **P3 - Revisor y QA (Luis):** Responsable de la calidad del código, la seguridad operacional (mitigación de fuga de datos sensibles), la revisión por pares (*Peer Review*) a través de hilos de discusión en Pull Requests y el merge final.

---

## Estructura del Repositorio
El árbol de directorios se estructuró de forma modular garantizando la separación de responsabilidades exigida:

```text
tp_org_empresarial/
├── .gitignore               # Exclusión de archivos pesados y cachés locales (.ipynb, pycache)
├── README.md                # Documentación principal e institucional del proyecto
├── datos/                   # Repositorio local de archivos (Protegido por .gitignore)
│   └── .gitkeep
├── resultados/              # Productos del análisis estadístico y reportes visuales
│   └── evolucion_ventas.png # Gráfico analítico
└── scripts/                 # Código fuente
    └── analisis.py          # Script principal de procesamiento con Pandas y Matplotlib
